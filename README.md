# Personal Portfolio Website

A clean, responsive personal portfolio website built with HTML and CSS. Perfect for showcasing your web development projects and skills.

## 🌟 Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Clean Layout**: Modern, professional design with smooth scrolling navigation
- **Easy to Customize**: Simple HTML/CSS structure that's beginner-friendly
- **Multiple Sections**: Hero, About, Skills, Projects, and Contact sections
- **Semantic HTML**: Proper HTML5 structure for accessibility and SEO

## 📁 File Structure

```
├── index.html      # Main HTML file with website structure
├── styles.css      # CSS file with all styling
└── README.md       # This documentation file
```

## 🎨 Sections Included

1. **Hero Section**: Eye-catching introduction with your name and title
2. **About Section**: Personal background and goals
3. **Skills Section**: Showcase your technical abilities
4. **Projects Section**: Display your portfolio projects
5. **Contact Section**: Ways for people to reach you

## ✏️ How to Customize

### Personalizing Your Information

1. **Update Your Name**: Replace "Your Name" throughout the HTML file
2. **Add Your Photo**: Replace the placeholder in the About section with your actual photo
3. **Edit Your Bio**: Update the paragraphs in the About section with your personal story
4. **Update Skills**: Modify the skills in the Skills section to match your abilities
5. **Add Projects**: Replace the placeholder projects with your actual work
6. **Contact Information**: Update email, LinkedIn, and GitHub links

### Customizing Colors

The main colors are defined in the CSS file:
- Primary color: `#3498db` (blue)
- Accent color: `#f39c12` (orange)
- Background gradient: `#667eea` to `#764ba2` (purple gradient)

To change colors, find these hex codes in `styles.css` and replace them.

### Adding More Projects

To add more projects, copy the project card structure in the HTML:

```html
<div class="project-card">
    <div class="project-image">
        <div class="image-placeholder">Your Project Screenshot</div>
    </div>
    <div class="project-content">
        <h3>Your Project Name</h3>
        <p>Your project description here.</p>
        <div class="project-links">
            <a href="#" class="btn-secondary">Live Demo</a>
            <a href="#" class="btn-secondary">GitHub</a>
        </div>
    </div>
</div>
```

## 🚀 Getting Started

1. Download or clone this repository
2. Open `index.html` in your web browser to view the website
3. Edit the HTML and CSS files to customize with your information
4. Host the files on any web server or GitHub Pages
